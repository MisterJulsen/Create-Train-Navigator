# 🚅 Create Railways Navigator (CRN)
![Logo](https://github.com/user-attachments/assets/2ee05cf6-c816-4dd7-8c24-6bb05062758e)

A Minecraft Create Mod addon that adds several new features related to train navigation, such as improved display boards, a navigator for searching routes, new schedule entries, and more.

## 🧩 Dependencies
- This mod requires [Create](https://modrinth.com/mod/create) or [Create Fabric](https://modrinth.com/mod/create-fabric).
- Versions with `C6` are compatible with Create 6, versions without this suffix are compatible with Create 5 (unless Create 6 is the only version available for that Minecraft version)
- Version `>= 0.9.0` require [DragonLib](https://modrinth.com/mod/dragonlib) to be installed! Older versions `<= 0.8.5` do **NOT** require DragonLib! Delete it from your mods folder. [Please read this post to see which versions of my other mods are compatible with each other](https://mrjulsen.net/mods/dragonlib/docs/blog/2026/03/01/dragonlib-3-compatibility/).

## ✅ Features
### Navigator
Use the Navigator which is inspired by the <a href="https://de.wikipedia.org/wiki/DB_Navigator" rel="nofollow">DB Navigator</a>, to find routes between two stations on your rail network. You will also see the departure times, delays, and other details about your journey.

### Advanced Displays
An improved version of Create's Display Boards, specifically designed for trains and stations. They show more detailed information about departing trains, such as the platform, line, delays, and other information. These displays can also be placed directly on the trains themselves, showing information such as the next stop or the terminus station.

### New Schedule Instructions
Distribute your trains evenly along your route with the Train Separation Instruction, use a more advanced version of wildcards with Prioritized Destination Instruction, or define the terminus with the Schedule Sections.
